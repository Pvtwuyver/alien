Posters en beeldmateriaal koppelen (TMDB)

Deze pagina toont per film een lege posterplek totdat assets/films.json een poster_url bevat. Filmposters zijn auteursrechtelijk beschermd materiaal, dus deze pagina bevat er zelf geen — en de TMDB-sleutel hoort nooit in client-side code terecht te komen, ook niet als fetch()-aanroep vanuit deze HTML, omdat iedereen de broncode van een GitHub Pages-site kan inzien en de sleutel dan direct leesbaar is.

In plaats daarvan haalt een GitHub Action de posterlinks tijdens de build op met de repository-secret TMDB_KEY, en schrijft alleen de resulterende URL's terug naar assets/films.json. De sleutel zelf verlaat de Action-omgeving nooit.

  1. Zorg dat de repository-secret TMDB_KEY al is ingesteld (Settings → Secrets and variables → Actions).
  2. Voeg scripts/fetch-posters.mjs en .github/workflows/fetch-posters.yml toe (bijgeleverd).
  3. Draai de workflow eenmalig handmatig via Actions → "Fetch TMDB posters" → Run workflow. De posterlinks worden dan als commit teruggeschreven naar assets/films.json.
  4. Ververs de site: elke poster verschijnt automatisch zodra poster_url gevuld is.
*/
